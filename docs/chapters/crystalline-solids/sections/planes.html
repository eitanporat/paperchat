Chapter 2 · Crystallographic Planes
pp. 70–75

A crystal is laced with flat families of atomic planes — the slip planes metals shear along, the diffraction planes X-rays reflect from, the cleavage planes minerals split on. To name any such plane unambiguously, crystallographers use Miller indices. The recipe looks odd at first glance (reciprocals? why?) but has a clear geometric logic.

The five-step procedure below builds the indices from scratch. One caveat before starting: the procedure requires the plane not to pass through the chosen origin. If it does, shift the origin by one unit-cell length along any convenient axis before you begin.

Use the sliders above to set h, k, l directly. The colored plane updates live: watch how setting an index to 0 makes the plane run parallel to that axis, while increasing the magnitude pulls the intercept closer to the origin (intercept = 1/index).

Worked example — the (01̄2) plane

A plane passes through the origin, so shift the origin by +b. New intercepts: A = ∞ (parallel to x), B = −b, C = c/2. Reciprocals: 1/∞ = 0, 1/(−1) = −1, 1/(½) = 2. No fractions to clear; indices are (0 −1 2). Overbar on the negative: (01̄2).

Three common planes and their geometry are worth memorizing. The (100) plane is parallel to the y–z face of the unit cell (two zero indices = cuts only one axis). The (110) plane cuts two axes at unit distance and runs parallel to z (one zero = parallel to one axis). The (111) plane cuts all three axes at equal distance (no zeros = it's the close-packed diagonal face in FCC).

Braces denote a family of planes: {100} collects all six face-planes of a cube — (100), (010), (001) and their negatives — which are distinct planes but identical in every physical sense. In cubic systems only, the direction [hkl] is perpendicular to the plane (hkl). This convenient coincidence does not hold for non-cubic crystals.

The Miller–Bravais indices (hkil) extend the system to hexagonal cells, which have three equivalent basal axes a₁, a₂, a₃ in the base plane plus a c-axis. The third basal index is always $i = -(h+k)$, so it carries no extra information — its purpose is to make symmetrically equivalent planes obvious (they show up as permutations of the same digits).

Reciprocals look weird until you realize "parallel to an axis" is just "crosses it at infinity."

Skipped: linear density, planar density, and d-spacing formula

Each family (hkl) has a characteristic interplanar spacing $d_{hkl}$. For cubic lattices: $d_{hkl} = a / \sqrt{h^2 + k^2 + l^2}$. X-ray diffraction peaks appear when $2 d_{hkl} \sin\theta = n\lambda$ (Bragg's law) — so knowing (hkl) lets you predict or identify diffraction angles. Planar density (fraction of area covered by atoms in a given plane) and linear density (along a direction) influence slip behavior and are computed the same way as for 3D packing but restricted to the plane.
