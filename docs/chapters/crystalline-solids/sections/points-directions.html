A crystal lattice is not just a picture — every atom site and every bond direction inside it has a precise, reproducible name. This section introduces the two naming systems: point coordinates (where is this site?) and direction indices (which way does this vector point?), then extends the direction system to four-index notation for hexagonal crystals.

Point Coordinates q r s

Place the origin at one corner of the unit cell. A point P inside (or on the boundary of) the cell is described by three fractions:

$$q = \frac{P_x}{a}, \quad r = \frac{P_y}{b}, \quad s = \frac{P_z}{c}$$

where $a$, $b$, $c$ are the cell edge lengths along $x$, $y$, $z$. The coordinates are written as three space-separated numbers with no brackets and no commas: q r s. Notable examples: 0 0 0 = origin corner, 1 0 0 = the next corner along $x$, ½ ½ ½ = body-center position.

Direction Indices [uvw]

A crystallographic direction is a vector. We care only about its orientation, not its magnitude, so we reduce it to the smallest integers $[uvw]$ that define the same line. Negative components are written with an overbar, e.g. $[\bar{2}21]$, read "bar-two, two, one."

Worked example — $[\bar{2}21]$

Tail at $(a,\,0,\,0)$, head at $(0,\,b,\,c/2)$. Differences in lattice units: $\Delta = (0-1,\;1-0,\;\tfrac{1}{2}-0) = (-1,\,1,\,\tfrac{1}{2})$. Multiply by 2 to clear the fraction: $(-2,\,2,\,1)$. GCD = 1, so the direction is $[\bar{2}21]$.

Many crystals have multiple directions that are crystallographically equivalent. The full set is called a direction family and written with angle brackets: $\langle uvw \rangle$. For a cubic crystal, $\langle 100 \rangle$ contains $[100]$, $[010]$, $[001]$, $[\bar{1}00]$, $[0\bar{1}0]$, $[00\bar{1}]$ — six directions, one family.

Hexagonal Four-Index Notation [uvtw]

The hexagonal lattice has three equivalent basal axes $\mathbf{a}_1$, $\mathbf{a}_2$, $\mathbf{a}_3$ at 120° to each other, plus a $z$-axis. Using all four makes symmetry-equivalent directions look the same numerically — a huge practical advantage. The fourth index $t$ is always redundant: $t = -(u+v)$.

Worked example — $[0\bar{2}1] \rightarrow [\bar{2}4\bar{2}3]$

Start with $[UVW] = [0\,\bar{2}\,1]$.
$u = (2 \cdot 0 - (-2))/3 = 2/3$
$v = (2 \cdot (-2) - 0)/3 = -4/3$
$t = -(2/3 - 4/3) = 2/3$
$w = 1$
Multiply through by 3 to clear fractions: $[2,\,-4,\,2,\,3]$. Divide by GCD = 2: $[\bar{2}\,4\,\bar{2}\,3]$. Wait — signs: $u$ original $= 2/3 > 0$, $v = -4/3 < 0$, $t = 2/3 > 0$, $w = 1$. After ×3: $(2, -4, 2, 3)$. GCD of $|2,4,2,3|$ = 1. Final answer: $[2\bar{4}23]$.

Why it matters
Direction indices are the language of deformation: slip planes, cleavage, and conductivity all favour specific $[uvw]$ families, so naming directions precisely is the first step toward predicting how a material will fail or flow.

Every direction in every crystal has a unique three-digit name.

Skipped: negative direction ambiguity and overbar typography

Crystallography conventions differ slightly between textbooks on how to typeset overbars. Some use Unicode combining overline (U+0305), others use the $\bar{n}$ LaTeX macro, and older texts write an explicit minus sign. All are equivalent. In machine-readable CIF files (Crystallographic Information Framework), directions are stored as signed integers, avoiding the overbar problem entirely.
